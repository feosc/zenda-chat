---
title: Página de Suporte
description: Chat público em URL dedicada, sem embed no site.
---

A **Página de Suporte** (help page) é um chat full-page acessível por link público — ideal para central de ajuda, e-mail de suporte ou QR code.

## URL pública

Formato: `https://www.zenda.ai/h/{slug-do-agente}`

O slug é gerado ao criar o agente. Copie o link em **Publicar** → **Página de Suporte** → **Gerenciar**.

## Ativar

1. Ative o interruptor do canal **Página de Suporte**.
2. Compartilhe o link (menu do site, assinatura de e-mail, WhatsApp).
3. Opcional: use o código **iframe** do dialog Gerenciar para embutir em uma página sua.

## Diferença do widget

| | Widget | Help page |
|---|--------|-----------|
| Instalação | Script no site | Só o link (ou iframe) |
| UX | Balão flutuante | Página inteira de chat |
| Login do visitante | Não | Não |

## Mesmo agente, mesmas fontes

Help page e widget usam o mesmo agente, fontes e ações. Conversas aparecem no **Activity** com canal distinto.
