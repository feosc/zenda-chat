## Canais em breve

No dashboard você verá também Gmail, Outlook, Messenger, Instagram e Telefone como **Em breve**. Quando lançarem, os guias serão adicionados aqui.

## Limite por plano

Cada plano define quantos canais podem estar **ativos** ao mesmo tempo:

| Plano | Canais ativos |
|-------|---------------|
| Grátis (trial) | 2 (widget + help page) |
| Starter | 2 |
| Growth | 3 |
| Pro / Enterprise | Ilimitados |

Se atingir o limite, ao tentar ativar outro canal o dashboard oferece upgrade.

## Fluxo geral

1. Escolha o canal no grid.
2. Use **Gerenciar** para copiar snippet, URL ou credenciais.
3. Ative o interruptor do canal.
4. Teste enviando uma mensagem real (não só Playground).
5. Acompanhe em **Activity**.

<Info>
  **Canal** ≠ **Ação**. Canal é onde o cliente fala; ação é o que o agente faz (Shopify, CTA, leads).
</Info>
